# OAuth 模型限制

ECP 支持对 OAuth 供应商的模型访问进行限制。限制在请求路由层由 CLIProxyAPI core 执行，因此不仅影响模型选择界面，也会阻止后续请求使用被排除的模型。

## 单个 OAuth 凭证

在 OAuth 凭证列表中点击该凭证的“模型”按钮，打开账号级模型设置。勾选模型后保存，规则写入该凭证的 `excluded_models` 字段，仅影响当前账号。

## 供应商全局规则

点击页面顶部的 OAuth 模型设置，选择供应商后保存规则。规则写入全局 `oauth-excluded-models`，影响该供应商下所有 OAuth 凭证。

## 规则格式

- 精确名称：`model-name`
- 通配符：`model-preview-*`
- 每行一条规则

账号级规则与供应商全局规则分开保存。模型目录不可用时仍可直接输入规则；未知模型名也会按规则传递给 core。

保存后，模型选择界面会隐藏匹配的模型，路由层也会拒绝被排除模型，避免仅限制 UI 而请求仍可绕过限制。
